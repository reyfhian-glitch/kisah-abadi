# Kisah Abadi – Wedding Organizer Website

Website premium untuk Kisah Abadi Wedding Organizer.

## File Structure (Flat / GitHub Upload Ready)

```
index.html          ← Halaman utama
booking.html        ← Form booking & pricelist
konsultasi.html     ← Halaman konsultasi
logo.png            ← Logo
foto1.png           ← Foto portofolio 1
foto2.jpg           ← Foto portofolio 2
foto3.jpg           ← Foto portofolio 3
video.mp4           ← Video hero background
PRICELIST.pdf       ← Pricelist layanan
.htaccess           ← Konfigurasi server Apache
README.md           ← Dokumentasi ini
```

## Deploy

Upload semua file ini ke root folder hosting (public_html).
Tidak ada folder — semua file langsung di root.

## Tech Stack

- HTML5, CSS3, Vanilla JavaScript
- Google Fonts (Cormorant Garamond, Jost)
- PDF.js untuk preview pricelist
